# SnapFit V8

GitHub Pages için tek dosyalı, çevrimdışı çalışabilen PWA.

## V8
- Profil başlangıçta zorunlu.
- Günlük su, kalori, protein, karbonhidrat, yağ ve manuel adım takibi.
- Her öğünde besin arama + gram/adet/porsiyon/ml + tek tek silme.
- 200+ besin kaydı ve geniş Türkçe yemek/içecek tabanı.
- 90+ ev/salon/kardiyo egzersizi; kas grubu, ekipman, seviye, set, tekrar/süre, dinlenme ve detay.
- Haftalık program oluşturma: Pazartesi–Pazar ayrı ayrı egzersiz ekleme.
- Hazır ev/salon programları ve haftalık şablonlar.
- İlk açılışta otomatik antrenman atanmaz.
- Günlük başarı 0–100; antrenman + beslenme + su + adım tamamlanınca 100/100 ve seri kaydı.
- Türkçe/İngilizce arayüz.
- V8 service-worker cache ile eski GitHub Pages sürümünün kalma ihtimali azaltıldı.

## Yayınlama
GitHub repository ana dizinine şu 5 dosyayı yükleyin: `index.html`, `manifest.webmanifest`, `icon.svg`, `sw.js`, `README.md`.
GitHub Pages → Deploy from a branch → `main` → `/ (root)` → Save.
